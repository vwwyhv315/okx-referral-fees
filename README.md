## Maker and taker fees explained without the jargon

A **taker** order fills against an order that is already sitting on the order book. Market orders usually behave this way, although the final fee depends on how the order is executed.

A **maker** order adds liquidity to the order book. A limit order that remains on the book before being matched is commonly treated as a maker order. However, a limit order that matches immediately can still be charged at the taker rate.

This is why “market order versus limit order” is not the complete explanation. The fee is based on the actual execution, not only the button or order type you selected.

For a simple spot trade:

text
Trading fee = applicable fee rate × filled trade amount


If you buy crypto, the fee may be deducted from the asset you purchased. If you sell crypto, it may be deducted from the sale proceeds. The precise currency and amount are shown in the order details after execution.
